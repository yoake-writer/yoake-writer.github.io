# 自主制作6件 レビュー（評価委員4名）

対象: works/houmon（訪問看護・6P）/ works/koumuten（工務店・6P）/ works/seitai（整体院・6P）/
works/salon（美容室LP）/ works/yado（宿LP）/ works/money（お金の講座LP）
実施: 2026-08-25 / コード・CSS・コントラスト値の実測を含む

## 1. デザイナー（構成・リズム・タイトル）

### 全体
- 6件で色を3色に絞る運用が全部で守られている。しかも業種ごとに変えている（木 #A9805B /
  ミント #7FC6B6 / 深緑+ベージュ #2E5E4E・#F5EFE6 / ピンクベージュ #C9A492 / 金茶+生成り
  #8C6E3F・#F7F4EE / 紺+黄 #1B2A4A・#F5C542）。ここは 6件並べたときにいちばん効いている。
- **書体は差別化できていない。** 実質「ゴシック5件＋明朝1件（yado）」で、あとは
  ウェイト差（salon 500 / koumuten・seitai 700）だけ。しかも全件が端末依存のローカル
  フォント指定で、Windows では Noto Sans JP が無く游ゴシックに落ちる。salon の
  「細字でおしゃれ」は Windows でいちばん崩れる設計。
- ページ幅の設計は良い。money 620 / salon 560 / yado 600 / houmon 720 という
  スマホ前提の狭幅と、koumuten 1080 / seitai 900 の PC 前提が、内容に合っている。

### リズム
- **yado がいちばん上手い。** 15:00 → 17:00 → 19:00 → 21:00 → 翌9:00 の時系列で
  「設備一覧をやめる」判断が効いている。section padding 84px・line-height 2.1 も、
  この構成でしか成立しない贅沢さで、他5件と混ざらない。
- **money は密度が高すぎる。** 22KB・写真3枚で、問題→共感→図→カリキュラム6本→講師
  →CTA→免責→FAQ が一直線。免責ブロックが CTA 内とフッターで**2回まるごと重複**して
  いる（意図的な念押しだと思うが、読み手には「同じ画面を2回見た」に近い）。
- houmon はカードの粒度が揃っていて読みやすい。ただしトップの流れが
  「入口2分岐 → 呼ばれる場面3枚 → 夜の話 → 救急の注意」で、**注意喚起で終わっている**。
  最後の印象が「怖い」になっている。
- seitai・koumuten は「症状/事例 → はじめての方へ → 次の一歩」で同じ骨格。2件並べると
  テンプレに見える。どちらかの2階層目の見せ方を変えたい。

### タイトル（title・h1）
- h1 は全体に強い。特に：
  - houmon「退院してからのことを、まだ誰にも聞けていない。」← 6件で最良。
  - koumuten「お湯がすぐ冷める。床のタイルが割れてきた。そろそろ、お風呂の替えどきです。」
  - salon「切った直後はいいのに、家でセットすると別人になる。」
- title タグは「名前（架空）｜〜」で統一されていて良い。ただし salon の title は
  `tsuki hair（架空）｜楽して、きれいになりたい。その楽を、ここで作ります` で
  タブでは「tsuki hair（架空）｜楽し…」までしか出ない。コピーが死んでいる。
- seitai の h1「夕方、席を立つとき、腰に手をやる。」＋ sub「その手が、自然と減っていくように。」
  は良いが、sub が h1 の中に入っているので見出しとして長い。

### 実装まわりで気になった点
- `.w { display:inline-block }` による文節固定は 6件で統一されていて、思想としては正しい。
  ただし koumuten（最大1080px）では手打ちの `<br>` と併用しているので、
  タブレット幅で意図しない位置に改行が残る箇所がある。
- money / salon / yado に `<main>` が無い（3サイトの下層ページには全部ある）。
- yado の一日の流れの写真6枚が `alt=""`。装飾扱いだが、この6枚は「一日」という
  コンテンツそのものなので、読み上げ環境では構成が丸ごと消える。

## 2. 想定読者（ヨアケを知らない・お金が不安だけど何もしていない30代看護師）

※ 各ページの本来の読者に置き換えつつ、いちばん自分に近い money を軸に読んだ。

### works/money を読んだ正直な感想
- 「銘柄は教えません。順番を教えます。」は刺さった。調べても人によって違うのが
  止まる原因、というのも当たっている。ここまでは良い。
- **ただ、これは私に向けて書かれていない。** 講師は「会社員として働きながら」で、
  出てくる例も固定費・通信・サブスク。**夜勤明けの生活も、看護師の給料の形も、
  出産・復職も、退職金の無さも、一言も出てこない。**
- 私が読みたかったのは「傷病手当金」の回が
  「自分が患者側になったときにいくら入るか」として書かれていること。第4回に
  傷病手当金は載っているのに、看護師なら毎日書類で見ている制度が
  「一般の人向けの説明」のトーンで書かれている。もったいない。
- 結論：**この1本だけは「看護師でなくても書ける」。** 他の5件には言えないことが、
  これには言える。
- 細かいところ：「9,800円の元は取れますか」→「取れますとは言えません。ゼロだった
  という方もいます」は信用した。ここは強い。

### 他の5件を読者として読んだとき
- **houmon**：これは他の人には書けない。「電話に出るのは留守電ではなく当番の看護師」
  「介護保険1割・30分で500円前後」「医療保険は原則週3回、特別指示があれば毎日」
  「退院前カンファレンスに同席」——ここは中の人の言葉。家族の立場なら電話する。
  ただし1点、`※ 直近では2026年6月に介護報酬の臨時改定` という記述だけ、
  出典が無いのに年月が具体的すぎて逆に不安になった。
- **salon**：「朝、何分使えますか」で分けるのは初めて見た。予約したくなる。
  ただし FAQ の中に
  **`【この項目は実案件ではお店に必ず確認します】` が本文として残っている**。
  お客としてこれを見たら「作りかけのページ」に見える。
- **yado**：「歩いて行ける店はありません。コンビニまで車で15分」を先に書くのは信用できる。
  未舗装の林道・冬のスタッドレスまで書いてあるのが決め手。ここまで書く宿は行きたい。
- **koumuten**：概算98万円・工期5日が先に出ているのが良い。「蛇口ひとつから」が効く。
- **seitai**：「回数券は売りません」が効く。整体で警戒するのはまさにそこ。

## 3. 営業担当（仕事の実績・営業の武器として使えるか）

### 使える点
- **6件・21ページを1人で完結させた事実が、いちばんの武器。** 構成・原稿・デザイン・
  実装が全部1人、というのは受注時に効く。
- 「実際の募集案件から逆算して作った自主制作です（クライアントはすべて架空）」——
  この一文が最強の営業文句なのに、**index.html のリード文の3行目に埋まっている**。
  ここは見出しに引き上げるべき。
- 架空である旨の開示が21ページ全部に入っている。ここを手抜きしていないのは、
  そのまま「この人は約束を守る」という証拠になる。
- 業種の幅（医療・建築・美容・宿泊・金融）が、そのまま「対応できる業種」の証明になる。

### 穴（受注機会を落としている箇所）
1. **21ページのどこからもポートフォリオに戻れない。** 全ページを grep したが、
   works/ 配下から本サイトへのリンクは **0本**。「制作: ヨアケ」もただのテキストで
   リンクではない。サンプルURLを単体で DM やスカウト返信に貼った瞬間、
   相手は行き止まりに入る。**問い合わせ導線が切れている。**
2. **OGP画像・OGPタグが21ページ全部に無い。** クラウドソーシングのメッセージや
   Slack・DM に URL を貼っても、サムネイルもタイトルも出ない。ただの青いリンクになる。
   ファビコンも無いので、相手が6タブ開いたとき全部「無地」で見分けがつかない。
3. **各サンプルに「制作意図」が載っていない。** ポートフォリオ側のカードには
   1〜2行の狙いが書いてあるが、ページ単体で見た人には届かない。
   実案件の提案時は「なぜこの構成にしたか」が価値なので、
   各サンプルの末尾に3行の制作ノートが欲しい。
4. **noindex を全件に入れている**（検索避けとして正しい判断）。
   結果、これらは検索経由の受注にはならない。ポートフォリオ経由の一本足であることを
   自覚した上で、1〜2 の穴を塞ぐ必要がある。
5. money の「2級ファイナンシャル・プランニング技能士（架空）」。
   架空だと明記されているので問題は無いが、**ヨアケさん本人の実資格と紛らわしい。**
   本人の資格を書けるなら実在のものにしたほうが、営業上は強い。

### 一言
6件は「作れます」の証明になっている。いま足りないのは「作れます」から
「相談してみよう」への線。**穴の1と2だけで、受注の入口が2つ増える。**

## 4. 超一流デザイナー（裁定）

3人の意見のうち、**いま直す価値があるのは3つだけ**。それ以外は今回やらない。

### 直すのはここだけ

#### ① salon の CTA のコントラスト（唯一の「不合格」）
`.btn-main { background:#C9A492; color:#fff }` は **2.28:1**。
自分で作った `lp-qa-checklist.md` の「本文と背景 4.5:1 以上」を、
**自分の作品が破っている。** ボタン文字は 0.98rem 太字（約15.7px）なので
大文字例外（18.66px以上）にも当たらない。
→ 塗りボタンだけ **#8A6553（5.16:1）** に落とす。#C9A492 は枠線・ラベル・
`.limit` の装飾用として残す。ブランドの印象はほぼ変わらない。
ついでに `.photo-note`（#7A7A7A on #FAF7F5 = 4.02）も一段濃くする。

#### ② works から本サイトへの戻り導線（営業の穴）
21ページのフッターにある「制作: ヨアケ」を、ポートフォリオへのリンクにする。
それだけ。バナーもモーダルも要らない。作業は21ファイルの1行置換。
**6件つくった労力に対して、いちばん回収率が高い1行。**

#### ③ money の読者を、ヨアケさんにしか書けない人に寄せる
想定読者の指摘が正しい。**6件のうち money だけが「誰でも書ける」。**
しかも皮肉なことに、ヨアケさんのブランド（看護 × AI × お金）の中心にいちばん近い題材。
講師を「夜勤のある医療職」に、第4回の傷病手当金を
「自分が患者側に回ったときにいくら入るか」に書き換えるだけで、
**この1枚が『看護師向け金融ライティングの実績』に変わる。** コピーは触らなくていい。
（架空の資格表記は残す／実資格に替えるかは営業判断）

### 今回やらないこと（意識的に見送る）
- 書体の差別化：Webフォント導入はロード時間と引き換え。6件のサンプルには重い。
- money の免責2回重複：金融というジャンル上、しつこいくらいで正しい。残す。
- houmon が注意喚起で終わる件：**あの順番は医療として正しい。** デザインの都合で
  順番を変えるべきではない。
- seitai と koumuten の骨格が似ている件：業種が違えば読者は比較しない。放置でよい。
- nav のタップ領域（実測 約33〜36px、チェックリストは44px）：
  PC前提のグローバルナビであり、優先度は①〜③の下。次の実案件までに直す。
- salon の `【この項目は実案件ではお店に必ず確認します】`：残ってはいけないが、
  ①のついでに消える程度の作業。①と同時に処理する。

### 総評
6件を1週間弱で並べた密度と、架空である旨を21ページ全部に入れた誠実さは、
そのまま営業材料になる。**足りないのは作り込みではなく、戻り道と、
「これはヨアケさんにしか書けない」と言える一本の存在。**
①②③を終えたら、次は7件目を作るより、この6件を持って提案に出るほうが早い。
