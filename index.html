執筆記事 — 医療・介護・制度

医療・介護は、書き手の経歴がもっとも問われる領域。臨床12年の現役看護師という経歴を明示して書けるのが、いちばんの強みです。
下の6本はすべて全文を公開しています。訪問看護・介護や産休・育休などの制度を扱った記事から並べているので、文体・構成・一次情報の当たり方を、そのままご確認ください。

NOTE — 介護 × 公的資料

認知症の家族への接し方｜訪問看護師が公的資料で確かめた「今日ひとつだけ」の選び方

「こう接すればいい」という一般論ではなく、公的資料にあたって「今日、ひとつだけ試せること」まで絞り込んだ記事。

記事を読む ↗ NOTE — 訪問看護

カレンダーは見えていた。でも生活は見えていなかった｜訪問看護で「見る」の意味が変わった日

訪問看護の現場で、「見えている」と「分かっている」の差に気づいた経験を、実務の視点で書いた記事。

記事を読む ↗ NOTE — 新人指導 × 患者

情報は集められるのに、患者さんにつながらない新人へ｜知識を足す前に「見る目的」を1つ渡す

知識量ではなく「何を見るために情報を集めるか」を先に渡す、という順番で組み立てた記事。

記事を読む ↗ NOTE — 訪問看護

提案しても続かないとき、先に何を見る？｜訪問看護で「生活から考える」ようになった

「続かない」を本人のやる気の問題にしない。生活の形から提案を組み立て直した実務記事。

記事を読む ↗ NOTE — 社会保障制度

看護師の産休・育休中のお金｜もらえる制度を先に知る

出産育児一時金・出産手当金・育児休業給付金・出生後休業支援給付金を、公立病院と私立病院で変わる窓口まで含めて1本に整理した制度解説記事。

記事を読む ↗ NOTE — 社会保障制度

産休・育休の社会保険料免除｜産休は知るだけ、育休は選べる

SNSで見かけた「産休は月初めだと損」という話を、厚生労働省の資料で確かめ直した記事。仕組みは実在するが数字が違い、選べるのは育休のほうだと示した。
