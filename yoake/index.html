About / Values

自分について

看護師として12年。

小児科病棟、成人病棟、手術室を経て、現在は訪問看護で働いています。

仕事の中では、患者さんへの説明、新人教育、マニュアルやチェックリストづくりにも関わってきました。

仕事の外では、記事を書いたり、Webや動画を作ったり、AIを自分の仕事にどう使えるか試したりしています。

大切にしていること

  1. 分からないことを、分かったふりをしない。
  2. うまくいかなかったことも隠さない。
  3. 専門家の言葉を、その人に通じる言葉へ直す。
  4. AIの答えをそのまま出さない。最後は自分で確かめて決める。
  5. 相手の時間を使っていることを忘れない。
