# tools/wrap-ja.py — 日本語の改行位置を文節に固定する

## 何のためのものか

日本語は、そのままだと1文字単位で折り返されます。

```
テンポを意識したカット編集・テロップ・サムネ
イル制作まで一貫して対応。
```

「サムネ／イル」のように単語の途中で切れると、素人っぽく、
機械が書いた文章のように見えます。

CSS の `word-break: auto-phrase` はこれを解決しますが、**Chrome 系にしか
効きません**。iPhone（Safari）では無効なので、上の崩れがそのまま出ます。

そこでこのスクリプトは、[BudouX](https://github.com/google/budoux)
（Chrome の auto-phrase と同じ Google の文節分割エンジン）で文節を判定し、
その境目に `<wbr>`（改行してよい位置）を埋め込みます。
CSS 側は `word-break: keep-all` にしてあるので、**`<wbr>` のある場所でしか
折り返しません**。これは全ブラウザで動きます。

```
テンポを意識したカット編集・テロップ・
サムネイル制作まで一貫して対応。
```

## 使い方

```sh
pip install budoux          # 初回のみ
python3 tools/wrap-ja.py    # index.html と portfolio/index.html を更新
```

**本文を書き換えたら、必ず再実行してください。** 何度実行しても結果は
同じになります（冪等）。

変更の有無だけ確認したいとき:

```sh
python3 tools/wrap-ja.py --check   # 要更新なら終了コード 1
```

## 触るときの注意

- **`class="w"` の中には `<wbr>` を入れません。** これは「ここで切らせない」
  ための既存の仕組みなので、意図的に除外しています。見出しなどで
  改行位置を自分で決めたいときは `class="w"` で囲ってください。
- **`KEEP_TOGETHER`** は、BudouX が割ってしまう複合語の例外リストです。
  「間に／合わない」「院内説／明動画」のような分割を見つけたら、
  ここにペアを足して再実行してください。
- 英数字の途中で切れていないかは、実行時に自動で検査されます。
- CSS の `overflow-wrap: anywhere` は、1文節が1行に収まらないときだけ働く
  保険です。`break-word` ではなく `anywhere` なのは、こちらが要素の最小幅
  にも反映され、狭い画面でグリッドがはみ出すのを防げるためです。
